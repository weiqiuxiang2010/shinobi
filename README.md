# shinobi
## 概要
HAL東京在学中、3年次に制作した作品  
自作ツールを活用して制作した3Dアクションゲーム  
ジャンル：3Dアクション  
言語：C++、HLSL
API：DirectX 9
担当範囲：全実装(個人制作)  
制作期間：6カ月  
操作デバイス：コントローラ、キーボードとマウス  
使用ライブラリ：Dear ImGui

## 実装内容
**ゲーム**  
- キャラクター制御
- カメラ制御
- AABB当たり判定、Sphere当たり判定、地面・斜面の当たり判定
- 敵AIの戦闘・巡回ロジック
- shader：Diffuse・Specularのライティング、影の描画
- パーティクルエフェクト、武器軌跡エフェクト
**マップエディター**  
- メッシュ生成
- 斜面編集
- オブジェクト配置
- 敵配置
- 敵巡回ルート配置
**モーションエディター**  
- 操作キャラクター、敵のモーション編集
- キーフレーム補間
- 補間曲線の編集

## 実装のポイント
- 自作のマップエディターとモーションエディターを活用し、ゲーム制作を効率化
- キャラクターの状態管理にStateパターンを採用
- Dear ImGuiを採用し、ツールのGUI開発工数を削減
  
## 操作説明
**<<タイトル>>**  
操作デバイス：キーボードとマウス  
項目の選択 : マウスホイール / ↑キー / ↓キー  
項目の確定 : マウス左ボタン / ENTERキー  
  
**<<ゲームプレイ>>**  
操作デバイス：XBOX360のコントローラ、キーボード  
XBOX360のコントローラの操作説明はゲーム内チュートリアルに記載  
キーボードの操作説明  
移動     : W/A/S/D  
走る     : SPACEキー + 移動  
回避     : SPACEキー  
攻撃     : Jキー  
武器変形 : Kキー  
敵にロックオン : ENTERキー  
  
**<<マップエディター>>**  
操作デバイス：マウス  
カメラのズーム : マウスホイール  
カメラ回転     : マウス右ボタンを押しながらマウスを移動する  
カメラ移動     : マウスホイールを押しながらマウスを移動する  
オブジェクトの配置とGUIの操作 : マウス左ボタン  
  
**<<モーションエディター>>**  
マウスを使用して操作する  
カメラのズーム : マウスホイール  
カメラ回転     : マウス右ボタンを押しながらマウスを移動する  
カメラ移動     : マウスホイールを押しながらマウスを移動する  
モデルの操作とGUIの操作 : マウス左ボタン
